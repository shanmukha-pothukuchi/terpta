TerpTA · design board · pass 1 of 3
TA scheduling for UMD, built to feel fast and quiet.
Two roles, one shell. TAs paint availability and log hours; coordinators define duties, generate a schedule and publish it. Every screen below is live: drag to paint, drag TA chips into slots, press ⌘K in the shell. Pass 1 covers the hero set; passes 2 and 3 fill in the remaining TA and coordinator screens.
Assumptions
· A discussion section counts 2h/week of credit (teaching + prep); an office-hour block is 2h; proctoring is 2h once. Async hours count toward the weekly cap spread over the two weeks before the due date.
· Every half-hour is Available, Prefer not or Unavailable. Unpainted time is Unavailable, so the solver never has to guess.
· Hard conflicts are red (class overlap, double-booked, date exception); over-cap is amber. Coordinators can still publish with conflicts, but the button says so.
· Google sign-in is the primary path; CAS is secondary. Domain restriction is enforced server-side, the UI just explains it.
Design system in one line
Near-black #0B0B0E page, surfaces step up to #0F0F13 → #15151A → #1A1A21. Borders are 1px at 8% white; focus adds a 3px 5%-white halo. Geist for UI at 12.5–13px, Geist Mono for times, section numbers and counts. Radii 8–14px. UMD red only on primary actions, the active nav icon, conflicts and the role badge. Green = available/OK, amber = prefer-not/over-cap, blue-gray = imported class blocks. Lucide icons at 1.5px stroke.

01Sign in· default
Google is the primary path, CAS the fallback. Role routing is invisible: the same button lands a TA on Availability and a coordinator on Roster. Try the buttons: Google goes to the loading state, then shows the domain error.
01Sign in· wrong-domain error
The rejected address is echoed so the fix is obvious. No modal, no shake.
02App shell· coordinator, ⌘K open, success toast
208px nav with the active item's icon in red, 52px top bar with the course/term switcher, ⌘K trigger, role badge and user menu. The palette groups Navigate / Actions / TAs and filters as you type; arrow keys and Enter work. Toasts sit bottom-right, one line, optional link, auto-dismiss.
TAAvailabilityScreen 05 · desktop and phone
05Availability· desktop 1440
Pick a brush, then click-drag across the Mon–Fri, 8am–8pm grid. Each run of the same state is one block, with the half-hour lines showing through it. Imported class blocks are locked and labelled. Autosave shows Saving… → Saved; Submit flips the badge and edits after submit change the button to Resubmit. Date exceptions live under the grid with an inline add form.
05Availability· phone
Same grid, finger-sized brushes, touch painting. Submit stays pinned at the bottom.
